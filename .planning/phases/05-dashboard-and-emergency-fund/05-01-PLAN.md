<objective>
Rename the seeded income category from Phase 2's actual value `"Redeemed Emergency"` to the roadmap/requirements wording `"Redeem Emergency Fund"` (D-02) — both for existing users (data migration) and for future registrations (seed constant edit). This is a prerequisite for BALN-05: `transactions/services.py::get_emergency_fund_balance()` (rewritten in Plan 05-02) matches income transactions by `category__name__iexact="Redeem Emergency Fund"` (D-01), and it can only match real user data once this rename has run.

Purpose: without this rename, every existing user's "Redeem Emergency Fund" income category literally does not exist in their data — BALN-05 would silently never fire for any pre-existing user.
Output: a reversible data migration renaming existing rows, an edit to the seed constant for future rows, and tests proving both.
</objective>

Wrap both functions with `migrations.RunPython(rename_forward, rename_reverse)` as the single operation.
