    - A month with zero total actual expense spending -> every group's percent_of_actual is None (not 0), even for a group that itself has $0 actual.
    - A month with zero total planned expense budget -> every group's percent_of_planned is None (not 0).
    - A transaction under a category that was soft-deleted AFTER the transaction was recorded still counts toward its original group's actual total for that month.
  </behavior>
  <action>
    Extend `dashboard/services.py::get_dashboard()`. Extend the `Category.all_objects.filter(user_id=user_id).values("id", "category_type")` query already added in Plan 05-04 Task 3 to also select `"group"` (`.values("id", "category_type", "group")`), so it becomes a single `id -> (category_type, group)` lookup reused by both the existing planned-total split and this new breakdown — do not add a second, separate query for the same rows.

    Compute actual-per-group via one query: `Transaction.objects.filter(user_id=user_id, category__category_type="expense", date__gte=month_start, date__lte=month_end).values("category__group").annotate(actual=Sum("amount"))` — grouped directly through the `category__group` FK traversal, which is correct regardless of the referenced category's current `is_active` status (the field value doesn't disappear when a category is soft-deleted). Build a `{group: actual_amount}` dict from this, defaulting missing groups to `Decimal("0.00")`.

    Compute planned-per-group in Python: iterate Plan 05-04 Task 3's already-isolated expense-type entries from `get_effective_amounts_for_user`, bucket each by its `group` from the extended lookup, and sum into a `{group: planned_amount}` dict, defaulting missing groups to `Decimal("0.00")`.

    For each of the four `Category.Group` choices, in enum declaration order (`needs`, `wants`, `investment`, `other`), build an entry: `{"group": <value>, "actual": <Decimal from the actual dict>, "planned": <Decimal from the planned dict>, "percent_of_actual": (actual / expense_total) if expense_total > Decimal("0.00") else None, "percent_of_planned": (planned / expense_planned_total) if expense_planned_total > Decimal("0.00") else None}`, using Task 2 of Plan 05-04's already-computed `expense_total`/`expense_planned_total` as the denominators. Add the resulting list as `"expense_breakdown"` on the response dict.

    Add tests to `dashboard/tests/test_dashboard.py` for each of the four `<behavior>` cases above.
