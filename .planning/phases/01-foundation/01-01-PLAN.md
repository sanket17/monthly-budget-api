## ASVS Level 1 Threats Addressed in This Plan

| Threat | Severity | Mitigation in This Plan |
|--------|----------|------------------------|
| Secret key in version control | HIGH | `SECRET_KEY` loaded from `.env` via django-environ; `.env` added to `.gitignore`; only `.env.example` committed |
| CORS credential theft | MEDIUM | `CORS_ALLOWED_ORIGINS` set from env var; `CORS_ALLOW_ALL_ORIGINS` never set to True |
| SQLite in production | HIGH | PostgreSQL 16 via Docker; no sqlite fallback in settings |
| Credential brute force | HIGH | DRF throttling classes defined in base.py: `AnonRateThrottle` 5/min on auth scope (endpoints wired in Plan 01-03) |
| Weak default permissions | HIGH | `DEFAULT_PERMISSION_CLASSES = [IsAuthenticated]` in base.py — AllowAny must be explicitly set per view |

**Not addressed yet (Plan 01-03):** Token theft, token replay, user enumeration — those threats require auth endpoints to exist.
</threat_model>
